The Cargo package is named `lific`.

## GitHub release binaries

Release binaries are published on [GitHub Releases](https://github.com/VoidNullable/lific/releases). Each release includes `sha256sums.txt` for checksum verification.

| Platform | Release file |
| --- | --- |
| Linux x86_64 | `lific-linux-x86_64` |
| Linux aarch64 | `lific-linux-aarch64` |
| macOS x86_64 | `lific-macos-x86_64` |
| macOS aarch64 | `lific-macos-aarch64` |
| Windows x86_64 | `lific-windows-x86_64.exe` |

Download the file for your platform. Compare it with the matching entry in `sha256sums.txt`. On Unix systems, make the downloaded file executable and place it in a directory on your `PATH`.

```bash
chmod +x lific-linux-x86_64
./lific-linux-x86_64 --help
```

On Windows, put `lific-windows-x86_64.exe` somewhere on your `PATH` and rename it to `lific.exe`. [Windows](/docs/windows) covers that platform in full, including WSL 2.

## Install with Cargo

Install the crate from crates.io with Cargo.

```bash
cargo install lific
```

Confirm that the binary is available.

```bash
lific --version
```

## Build from source

Source builds use the repository's [devenv](https://devenv.sh/) environment.
Release artifacts always include the web UI; the task graph builds it before
the Rust binary.

```bash
git clone https://github.com/VoidNullable/lific
cd lific
devenv allow
devenv shell
# inside the devenv shell:
devenv tasks run lific:debug-build
```

For a Linux release artifact:

```bash
devenv --profile release-linux tasks run lific:release:x86_64-unknown-linux-gnu
```

Use `release-darwin` with an Apple target for macOS builds. The debug binary
and release artifacts are written beneath `target/`.
