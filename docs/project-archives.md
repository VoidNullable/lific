# Project archives

The maintained guide is at [lific.dev/docs/project-archives](https://lific.dev/docs/project-archives).

It covers CLI and browser transfers, preserved data, attribution, archive limits, validation and cutover.
Lific 3.0 writes archives in format 3, which keeps issue, page and plan numbers taken even after their items are permanently deleted. Import a 3.0 archive into Lific 3.0 or later; format 1 and 2 archives still import.
For the documentation shipped with this checkout or release tag, read the
[MDX source](../site/content/docs/project-archives.mdx).
