# Public projects

The maintained guide is at [lific.dev/docs/public-projects](https://lific.dev/docs/public-projects).

It covers publication, what readers can and cannot see, reading without an account, request limits and hosting precautions.
A published project is read at its ordinary links and API routes, by visitors with no account and by every account, API key and MCP connection; changing anything still needs a role. The separate `/public` view of Lific 2.x is gone: `/public/api` routes answer `404` and old `/public/APP/...` links answer `301` to `/APP/...`.
For the documentation shipped with this checkout or release tag, read the
[MDX source](../site/content/docs/public-projects.mdx).
